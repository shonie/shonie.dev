1. Project overview

- This project contains the code of the site of Oleksandr Starnikov who is a Solution Architect, Fullstack developer, Data engineer and Technical Lead all at once.
- A statically build and deployed Next.js web app
- App Router should be used for Routing
- CI is Github Actions
- Styling engine is Tailwind CSS
- Built mobile-first but should be not less beautiful on desktop
- All code should be written in TypeScript with SOLID principles in mind
- As low-maintenance as possible

2. Project structure

The main application source code lives in the following folders. Purpose of the folder is given in parantheses folliowing the folder name.

- public
  - data (directory for static JSON files)
    - dev-stats (external ETL pipeline will regularly post JSON files to this folder so that the app can get data without API calls)
  - assets
    - images (folder for high-quality images for the site)
    - icons (folder for SVG icons)
- src
  - app (Next.js app)
  - components (reusable React components eg. Button, Header, etc)
  - lambdas (backend lambdas)
  - types (folder for common TypeScript typings)

3. Conventions
   3.1. All files should be named in kebab-case
   3.2. Tailwind's best practices of using utility classes should be followed
   3.3. All React components' props should be typed with TypeScript
   3.4. It should be a statically-deployable Next.js app, none of the [Server functions](https://nextjs.org/docs/app/guides/static-exports#unsupported-features) are needed

4. Ignore files

- .next/
- node_modules/
- .turbo/

- dist/
